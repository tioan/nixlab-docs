# Modules

The 20 modules under `modules/` carry the configuration shared by all hosts; every file explains in its header comment why it is the way it is. The public version contains them anonymised under `modules/` – as a reference, not directly importable: some read `hosts/<host>/*.yaml` and assume sops-nix. Five have options of their own.

| Module | Purpose | Options / notes |
| --- | --- | --- |
| [auto-upgrade-git.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/auto-upgrade-git.nix) | Nightly `nixos-rebuild switch` of the checkout, fast-forwarded to a signed `main` first; never commits or pushes | `services.autoUpgradeGit`: `enable`, `flakeDir`, `flakeAttr`, `updateInputs`, `dates`, `allowReboot`, `rebootWindow`, `deployKeySecret`, `gitAuthorEmail`, `holdFile`, `holdCheck`, `pull`, `verifySignatures` |
| [auto-upgrade-git-pull.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/auto-upgrade-git-pull.nix) | Pull that fast-forwards only to an SSH-signed commit (trusted signers, plus lock-only signers for flake.lock commits); used by auto-upgrade-git and nix-cache | package, built through `services.autoUpgradeGit.verifySignatures` |
| [log-shipping.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/log-shipping.nix) | journald and nginx logs to VictoriaLogs via Vector | `services.logShipping`: `enable`, `victoriaLogsUrl` |
| [metrics-shipping.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/metrics-shipping.nix) | vmagent scrapes the local exporters and remote-writes to VictoriaMetrics | `services.metricsShipping`: `enable`, `remoteWriteUrl`, `exporterPorts` |
| [disk-health.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/disk-health.nix) | SMART of physical disks: smartd self-tests (short weekly, extended monthly, staggered per disk), smartctl_exporter, `smart_selftest_*` textfile metrics, dashboard Disk Health | `services.diskHealth.devices` (by-id paths; the order decides the test slot); on ursalia and tummi |
| [home-wifi.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/home-wifi.nix) | WLAN on the home network "homelab": 5 GHz preferred, all bands as fallback, passphrase from sops, optionally a wired port with a higher metric as fallback, WLAN metrics (`wifi_link_*`) | `services.homeWifi`: `enable`, `interface`, `wiredFallback`; on tummi |
| [public-probes.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/public-probes.nix) | Probes the public endpoints from `inventory.json` from outside with the blackbox exporter, over IPv4 and IPv6 separately; what each endpoint must answer and which host probes it is in `public-probes-targets.nix` (a public endpoint without an entry stops the evaluation). Job `<host>-public-probes` | `services.publicProbes.enable`, `heartbeat.sopsFile` (ping to healthchecks.io while all of the host's probes succeed); #169 |
| [samba-mesh.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/samba-mesh.nix) | Samba for the mesh only: SMB3, macOS friendly, no guests, no NetBIOS; passwords of the Samba accounts from sops | `services.sambaMesh`: `enable`, `users`; shares, accounts and ACLs stay with the host; on ursalia and tummi |
| [deploy-hold.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/deploy-hold.nix) | Hold for `just try`: `nixos-hold`, metric `nixlab_deploy_hold_since_seconds`, warning in the login shell | on cuckoosegg too – [Test a branch before merging](../how-to/try-branch.md) |
| [deploy.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/deploy.nix) | The lab's policy for auto-upgrade-git: GitHub deploy key, pinned host key, reboot window 04:00–06:00 | kept apart from the mechanism so that stays reusable |
| [nix-cache.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/nix-cache.nix) | The lab's own binary cache in Garage (`s3://nix-cache`): substituter and read key on every host; on ursalia the nightly lock update, build of every host and upload | `services.nixCache.prebuild`: `enable`, `updateInputs`, `dates`; secrets from `just nix-cache-secrets` |
| [acme.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/acme.nix) | ACME defaults for every TLS host: DNS-01 against deSEC | token from `hosts/<host>/desec.yaml` (from Tofu) |
| [netbird.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/netbird.nix) | NetBird client in the mesh, registration via setup key, local metrics | setup key from `hosts/<host>/netbird.yaml` (from Tofu) |
| [ssh.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/ssh.nix) | Who may log in from where: root only on the mesh address (admin jump as break-glass) | keys stay per host |
| [firewall.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/firewall.nix) | Only 22/80/443 public | the mesh interface is trusted in netbird.nix |
| [crowdsec.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/crowdsec.nix) | CrowdSec engine and firewall bouncer, whitelist for the lab hosts and for nix cache lookups | workarounds for bugs in the nixpkgs modules, documented in the header |
| [networking.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/networking.nix) | ifstate skeleton, systemd-resolved with DNS over TLS, no fallback resolvers | addresses and routes stay in the host config |
| [metrics.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/metrics.nix) | Prometheus exporters per host | protected by the firewall instead of bind addresses |
| [textfile-metrics.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/textfile-metrics.nix) | node_exporter's textfile collector; every writer runs as its own user and may write only `<dir>/writers/<name>/` (#320) | `services.textfileMetrics`: `directory`, `metricPrefix`, `writers.<name>` (script, timer, exceptions as `hardening`), `directories.<name>` for units defined elsewhere; root jobs (upgrade, backup) keep the root directory |
| [hardening.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/hardening.nix) | One systemd sandbox profile for services, levels base/standard/strict, network none/netlink/loopback/any (#18) | `systemd.services.<name>.hardening`; every exception (capabilities, devices, system calls, writable paths) is an argument, the header says what each directive breaks |
| [logging.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/logging.nix) | Bounds journald, which otherwise grows up to 4 GB | |
| [qemu-guest.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/qemu-guest.nix) | QEMU guest agent with an RPC deny list: snapshots yes, shell and file access over the channel no | |
| [container-pins.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/container-pins.nix) | Podman images pinned by digest; refuses unpinned images and the auto-update label. Not in the shared list: imported by each container's file (ursalia) | `services.containerPins`: `images.<name>` (`image`, `tag`, `digest`, `source`, read-only `ref`), `enforce`; pins in `hosts/<host>/container-images.json`, bump with `just container-bump` ([Update a container image](../how-to/container-images.md)) |
| [watchdog.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/watchdog.nix) | Hardware watchdog held by systemd: PID 1 opens the device and pings it every half timeout; if PID 1 or the kernel hangs, the hardware resets the host. Holding it also keeps any other process (procd in a container, #117) from arming it. Marker metric `nixlab_hardware_watchdog_enabled`, alert `HardwareWatchdogInactive` | `services.hardwareWatchdog`: `enable`, `device` (default `/dev/watchdog0`), `softdog`, `blacklistedModules` (other watchdog drivers, so there is exactly one); timeout = the device's own (`RuntimeWatchdogSec=default`); on ursalia and tummi (`iTCO_wdt` blacklisted), aldrin and grammi (QEMU iTCO), cuckoosegg (i6300esb from Proxmox); `softdog` (kernel software watchdog, plus `kernel.panic=10` and `softlockup_panic`) on zummi |
| [nix.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/nix.nix) | Nix daemon, garbage collection, store optimisation | |
| [docs-site.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/docs-site.nix) | The private docs site (flake package `docs-site`) under `doku` on the mesh | `services.docsSite`: `enable`, `package`, `fqdn`, `allow` (default: the whole mesh; in the lab only the admin devices from `admin-peers.json`); on aldrin and ursalia |
| [lab.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/lab.nix) | Lab constants, declared once; the values come from `inventory.json` (`labConstants` in `flake.nix`) | `lab.mesh`: `ipv4`, `ipv6`, `networks` (read-only list of both) |
| [web-baseline.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/web-baseline.nix) | Security headers, default servers (444 / redirect) and the vhost helper for every nginx, see [Web baseline](../explanation/web-baseline.md) | `lab.web.securityHeaders`, `lab.web.nginx.headers` (read-only), `lab.vhosts.<name>`: `port`, `websockets`, `meshOnly`, `allow`, `proxyListener`, `maintenance`, `waf`, `serverName`, `extraConfig`, `nginx`; on aldrin, ursalia, zummi and grammi (headers for Traefik) |
| [maintenance.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/maintenance.nix) | Maintenance mode for nginx and Traefik: a flag file switches a name to a 503 page, the same page on 502/504 | `services.maintenance`, see [Maintenance mode](../how-to/maintenance.md) |
| [hotfixes.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/hotfixes.nix) | Package hotfixes that switch themselves off and warn once nixpkgs has the fix | module argument `hotfix`, overlays from `modules/hotfixes/`, see [Hotfix a package](../how-to/hotfix.md) |
| [base.nix](https://github.com/tioan/nixlab-docs/blob/main/modules/base.nix) | Locale, console, time and tools for debugging | |
